# 架构调整说明

## 本轮范围

- 重建网站端前端原型，不修改后端业务代码。
- 页面扩展为首页工作台、AI 聊天、个人时间轴、个人画像、自主 DIY。
- 前端使用 mock 数据验证展示方向；聊天页预留真实 `POST /api/v1/chat`。

## 架构边界

```text
User Input -> FastAPI -> Master Agent -> Life Understanding Agent -> Interaction Agent -> assistant_response
```

- 后端继续遵守 `API -> Service -> Agent -> Tool -> Database`。
- 前端仅通过 HTTP API 交互，不访问 LLM 和 Database。
- Agent 之间通过统一 `AgentState` 传递数据。
- 不修改冻结 API 字段、变量命名和 Agent 核心职责。

## 前端实现

- 技术栈：React + TypeScript + Vite。
- 样式：纯 CSS + 简单组件。
- 视觉：参考 `图片风格原型定制` 中的深色强调卡片、浅蓝辅助色、圆角卡片和底部导航。
- mock 数据：`frontend/src/mocks/life_events.json`、`frontend/src/mocks/user_profile.json`。
- 交互 mock：`timeline_events.json` 按日期组织时间轴，`workspace.json` 支持任务与项目编辑。
- 接口代理：开发环境 `/api` 代理到 `http://localhost:8000`。

## 本轮新增交互

- 首页任务完成状态切换。
- 时间轴日期切换、事件类型筛选和事件详情展开。
- DIY 项目编辑、任务增删、完成状态切换和 localStorage 持久化。

## 明确不做

- Memory Agent 页面、Reflection Agent 页面、Planning Agent 页面。
- pgvector RAG 页面、通知系统、移动端工程。
- 后端业务代码和数据库结构修改。

## 网页联调冻结说明

统一用户 ID：`10001`；前端开发地址：`http://localhost:5173`；后端地址：`http://localhost:8000`。Vite 将 `/api/*` 代理到后端，后端同时允许 localhost/127.0.0.1:5173 的 CORS。

Chat API 请求示例：

```json
POST /api/v1/chat
{"user_id":10001,"conversation_id":"web-demo-20260826","user_input":"今天学习数学2小时，有点累"}
```

成功响应示例：

```json
{"assistant_response":"已记录。","intent":"record_event","extracted_events":[{"event_type":"study","event_content":"今天学习数学2小时，有点累"}]}
```

时间轴回读：`GET /api/v1/life-events?user_id=10001&days=7`

```json
{"items":[{"life_event_id":1,"user_id":"10001","conversation_id":"web-demo-20260826","event_type":"study","event_content":"今天学习数学2小时，有点累","event_time":null,"emotion":"tired","importance_score":0.7,"source":"text","source_text":"今天学习数学2小时，有点累","created_at":"2026-08-26T10:00:00+08:00"}],"count":1}
```

Reflection 与 Planning 仍通过同一个 Chat API，分别发送“最近为什么学习效率下降？”和“根据我最近的状态，帮我安排明天的学习计划”，验收 `intent` 分别为 `reflection`、`planning`。

错误约定：参数错误返回 HTTP 400、`{"success":false,"error_code":"INVALID_REQUEST",...}`；服务/数据库错误返回 HTTP 500、`error_code` 为 `AGENT_PROCESSING_ERROR` 或 `INTERNAL_SERVER_ERROR`。前端收到非 2xx 时显示“请求失败”并标记“未写入时间轴”，不会再追加 mock 成功回复。

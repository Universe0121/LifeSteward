# LifeSteward

LifeSteward is a Chinese personal life companion demo. It turns natural-language
records into searchable life events, reflections, time-based plans, and weekly
reports. The repository contains the web client, an Expo/React Native Android
client, and the FastAPI service used by both clients.

## Architecture

```text
Web / Android client -> HTTP API -> FastAPI service -> Agent / Service -> Tool -> PostgreSQL + pgvector
                                                              \-> Redis
```

Clients never connect directly to PostgreSQL, pgvector, Redis, an LLM provider,
or an Agent. The API keeps its existing `snake_case` contract.

## Repository Layout

- `backend/` FastAPI application, agents, services, tools, migrations, and tests
- `frontend/` Vite + React web client
- `mobile/` Expo TypeScript client; the Android project is generated by Expo CNG
- `docs/public_demo_setup.md` reproducible local/public demo operations
- `docker-compose.yml` PostgreSQL/pgvector and Redis services
- `scripts/` Windows demo start, stop, and health-check scripts

## Requirements

- Windows 10/11
- Python 3.11 or newer
- Node.js LTS and npm
- Docker Desktop with Linux containers
- Android Studio with an Android SDK for APK builds (optional for web-only use)

## Backend Setup

From PowerShell at the repository root:

```powershell
python -m pip install -r backend\requirements.txt
Copy-Item backend\.env.example backend\.env
```

Edit `backend\.env` locally. At minimum configure:

- `POSTGRES_DSN` for the PostgreSQL database
- `REDIS_URL` for Redis
- `LLM_PROVIDER`, `MODEL_NAME`, and the matching provider key
- `DASHSCOPE_API_KEY` when using the Qwen provider
- speech settings when voice transcription is enabled

Never commit `backend\.env`, API keys, database passwords, or audio recordings.

Start dependencies and apply migrations:

```powershell
docker compose up -d
cd backend
python scripts\run_migrations.py
```

Start the API:

```powershell
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

Health probes:

```text
GET http://127.0.0.1:8000/health/live
GET http://127.0.0.1:8000/health/ready
```

`/health/live` only checks that the process is running. `/health/ready` checks
database, pgvector, migrations, Redis, application wiring, and required runtime
configuration. It returns `503` until the service is ready.

## Web Client

```powershell
cd frontend
npm install
Copy-Item .env.example .env
npm run dev
```

Open the Vite URL shown in the terminal. `VITE_API_BASE_URL` may be a backend
root such as `http://127.0.0.1:8000`; the client adds `/api` where required.

## Android Client

```powershell
cd mobile
npm install
Copy-Item .env.example .env
npm run typecheck
npm test
npx expo start --web
```

Set `EXPO_PUBLIC_API_BASE_URL` to a reachable backend root and keep
`EXPO_PUBLIC_API_MODE=real` for live data. The app also supports an explicit
`mock` mode for UI-only development. In a built app, the **定制** tab can test
and persist a changed HTTPS backend address, so a temporary tunnel can change
without rebuilding the APK.

Build an installable debug-signed release APK. Expo regenerates the ignored
Android project from the checked-in app configuration:

```powershell
cd mobile
npx expo prebuild --platform android --non-interactive
cd android
.\gradlew.bat assembleRelease
```

The APK is written below `mobile\android\app\build\outputs\apk\release\`.
The generated `mobile\android\` directory is intentionally not committed;
`npx expo prebuild` recreates it from the repository source.
The debug signing configuration is for demo evaluation only; use a private
release keystore for production distribution.

## Public Demo

The Windows runner starts Docker dependencies, applies both migrations, starts
the backend, and optionally creates an HTTPS temporary tunnel. It prefers a
Cloudflare Quick Tunnel, then falls back to localhost.run and localtunnel. It
maintains a small local watcher for backend/tunnel process failures:

```powershell
.\scripts\start_public_demo.ps1 -Subdomain all-cloths-hang
.\scripts\check_public_demo.ps1
.\scripts\stop_public_demo.ps1
```

Use `-NoTunnel` when testing only on the local machine. The current public URL
is stored only in the ignored `.lifesteward-runtime\public-url.txt`. The Quick
Tunnel hostname is temporary and may change after a reconnect; the mobile app's
**定制** tab can test and persist the new runtime URL without an APK rebuild.
Free tunnel providers cannot guarantee a permanent URL or uptime; a cloud server
or named tunnel is required for production availability.

## API Surface

- `POST /api/v1/chat`
- `GET /api/v1/life-events?user_id=...&days=...`
- `POST /api/v1/speech-to-text`
- `GET /api/v1/weekly-reports?user_id=...&limit=...`
- `POST /api/v1/weekly-reports/generate`
- `GET /api/v1/weekly-reports/{report_id}/poster`

The web and Android clients keep ordinary tasks separate from minute-level daily
plans. Tasks have a date but no clock time; plans have `HH:mm` start time and a
duration.

## Security

This repository is intended to be publicly reviewable. Only sanitized example
configuration belongs in Git. Rotate any key that has been exposed outside the
local `.env` files before a public release.

Python变量
	使用：snake_case
	eg: user_id  
		memory_content
数据库字段
	使用：snake_case
	eg: user_id  
		create_time
		event_type
API JSON 
	保持：snake_case
	例如：{
		"user_id":10001,
		"message":"hello"
		}

聊天命名规范

Agent State变量
	文件：agents/state.py
	定义：class AgentState(TypedDict):
    # 用户身份
    user_id: str
    # 当前会话
    conversation_id: str
    # 用户输入
    user_input: str
    # 意图分类
    intent: str
    # 当前事件
    extracted_events: list
    # 检索记忆
    retrieved_memories: list
    # 用户画像
    user_profile: dict
    # 当前目标
    current_goal: dict
    # 当前计划
    generated_plan: list
    # 复盘结果
    reflection_result: dict
    # 最终回复
    assistant_response: str

Memory Agent变量
	查询关键词
		统一：memory_query
		例如：memory_query =
		"用户过去学习失败原因"
	embedding向量
		统一：query_embedding
		例如：query_embedding=[
		0.123,
		0.456
		]
	检索结果
		统一：retrieved_memories
		结构：retrieved_memories=[
		{
		"memory_id":1,
		"memory_content":
		"用户压力大时减少任务有效",
		"similarity_score":0.86
		}
		]
	新生成长期记忆
		统一：new_memory
		例如：new_memory={
		"memory_type":
		"habit",
		"memory_content":
		"用户晚上学习效率较低"
		}
